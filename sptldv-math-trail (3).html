Level 0

🌱 Get Ready — Memahami Batasan Nyata

Sebelum menulis rumus, mari kita pahami: "Apa yang sebenarnya sedang dibatasi dalam kehidupan sehari-hari?"

🔍 Apa Itu Pertidaksamaan Linear Dua Variabel?

Dalam dunia nyata, kita jarang berurusan dengan tanda sama dengan persis (=). Uang saku kita punya batas maksimal, kapasitas ruangan ada batas daya tampung, dan waktu belajar kita terbatas.

Bentuk Umum PtLDV:
• ax + by ≤ c
• ax + by < c
• ax + by ≥ c
• ax + by > c
Keterangan: x dan y adalah variabel; a dan b adalah koefisien; c adalah konstanta pembatas.

Contoh Kontekstual Kantin:

Bayangkan kamu membawa uang saku Rp20.000 ke kantin sekolah. Kamu ingin membeli:

  • Roti bakar seharga Rp4.000 / buah (x)
  • Es teh jumbo seharga Rp2.000 / gelas (y)

Pertanyaan filosofisnya: Apakah kamu harus menghabiskan uang pas Rp20.000? Tentu tidak! Kamu boleh belanja kurang dari Rp20.000, asalkan tidak melebihi anggaran.

Model Matematika:
4.000x + 2.000y ≤ 20.000  →  2x + y ≤ 10, dengan x ≥ 0, y ≥ 0

🧠 Latihan Konseptual Level 0

Pilihlah analisis yang tepat untuk situasi kontekstual di bawah ini.

Kasus Koperasi Sekolah:

Pak Guru meminta panitia kelas membeli buku tulis (x) seharga Rp5.000 dan pulpen (y) seharga Rp3.000. Dana kas kelas yang disediakan paling banyak Rp60.000. Panitia juga wajib membawa minimal 10 barang total agar cukup dibagikan ke siswa berprestasi.

Perhatikan kata "paling banyak" artinya nilai tidak boleh lebih besar dari batas (≤), sedangkan "minimal" artinya nilai harus sama dengan atau lebih besar dari batas (≥).
Ada dua batasan berbeda: Batasan Anggaran Kas (5.000x + 3.000y ≤ 60.000) dan Batasan Kuantitas Fisik Barang (x + y ≥ 10).

🤔 Pertanyaan Kritis:

"Mengapa dalam masalah nyata di sekolah kita hampir selalu menambahkan syarat x ≥ 0 dan y ≥ 0?"

Jawaban: Karena kuantitas fisik benda (makanan, minuman, buku) tidak mungkin bernilai negatif di dunia nyata!

Level 1

📏 Draw the Line — Memahami Garis Batas

Garis batas membagi bidang koordinat Kartesius menjadi dua bagian. Mari pelajari cara menggambar dan jenis garisnya!

📐 Langkah Menentukan Garis Batas

  1. Ubah tanda ketidaksamaan menjadi sama dengan (=).
    Contoh: Dari 2x + y ≤ 8 menjadi persamaan garis batas 2x + y = 8.
  2. Tentukan titik potong sumbu-X (saat y = 0):
    2x + 0 = 8 → x = 4. Diperoleh titik potong (4, 0).
  3. Tentukan titik potong sumbu-Y (saat x = 0):
    2(0) + y = 8 → y = 8. Diperoleh titik potong (0, 8).
  4. Tarik garis lurus melalui kedua titik tersebut.
⚠️ Perbedaan Jenis Garis Batas:
• Garis Penuh (Solid): Digunakan untuk tanda ≤ atau ≥. Artinya titik-titik tepat di sepanjang garis merupakan bagian dari penyelesaian.
• Garis Putus-Putus (Dashed): Digunakan untuk tanda ketidaksamaan murni (< atau >). Artinya titik tepat di garis batas TIDAK termasuk penyelesaian.

Uji Cepat Pemahaman:

Jika pertidaksamaannya adalah 3x + 4y > 12, jenis garis apa yang harus digambar?

Pilih koefisien untuk melihat garis batas terbentuk secara otomatis pada bidang koordinat.

💡 Amati: Titik potong sumbu X & Y dihitung otomatis: (c/a, 0) dan (0, c/b). Garis ditarik menghubungkan kedua titik tersebut!
Level 2

🎨 Find the Region — Menentukan Daerah Penyelesaian

Jangan hanya menghafal "kurang dari arsir ke bawah". Pahami metode Titik Uji!

🎯 Metode Titik Uji (Test Point)

Untuk mengetahui sisi mana yang harus diarsir sebagai Daerah Penyelesaian (DP):

  1. Pilih sebuah titik sembarang yang tidak berada di atas garis batas. Titik paling mudah adalah titik asal (0, 0).
  2. Substitusikan nilai x = 0 dan y = 0 ke pertidaksamaan.
  3. Cek kebenaran pernyataan:
    • Jika bernilai BENAR, maka daerah yang memuat titik (0, 0) adalah Daerah Penyelesaian.
    • Jika bernilai SALAH, maka daerah di seberang titik (0, 0) adalah Daerah Penyelesaian.
Contoh Nyata: 2x + 3y ≤ 12
Uji titik (0, 0):
2(0) + 3(0) ≤ 12  →  0 ≤ 12  (BENAR!)
Karena bernilai benar, maka sisi bidang koordinat yang memuat titik (0, 0) diarsir sebagai daerah penyelesaian!

Level 3

⚔️ Find the Intersection — Sistem Pertidaksamaan (SPtLDV)

Ketika dua batasan atau lebih bekerja sekaligus, daerah penyelesaiannya adalah irisan bersama!

🧩 Konsep Irisan Daerah (Feasible Region)

Suatu sistem terdiri dari gabungan beberapa pertidaksamaan. Solusi akhirnya adalah himpunan titik (x, y) yang memenuhi seluruh pertidaksamaan secara serempak.

Contoh Sistem Pertidaksamaan:
1. x + y ≤ 10   (Batasan Kapasitas Total)
2. 2x + y ≤ 14   (Batasan Anggaran / Bahan)
3. x ≥ 0, y ≥ 0   (Kuadran I / Non-Negatif)

Kontrol Lapisan Visual (Interactive Layering):

Centang/hilangkan centang untuk mengamati bagaimana masing-masing garis dan arsiran membentuk irisan akhir:

🔍 Titik Sudut (Corner Points):
Irisan daerah penyelesaian dibatasi oleh poligon dengan titik sudut:
(0, 0), (7, 0), (4, 6) [titik potong kedua garis], dan (0, 10).

📈 GeoGebra Lab SPtLDV

Uji model matematikamu sendiri secara bebas dengan GeoGebra Graphing Calculator resmi.

💡 Alur Laboratorium GeoGebra:

COBA → AMATI → BANDINGKAN → JELASKAN
  1. Ketik persamaan atau pertidaksamaan pada panel GeoGebra sebelah kiri (misal: 2x + y <= 10).
  2. Tambahkan pertidaksamaan kedua (misal: x + 2y <= 8).
  3. Gunakan operator && untuk melihat irisan: 2x + y <= 10 && x + 2y <= 8 && x >= 0 && y >= 0.
  4. Tandai titik potong menggunakan alat Intersect.

🎤 Share Your Solution — Presentasi Kelompok

Setelah melakukan observasi di posmu, susunlah hasil temuan kelompokmu menjadi bahan presentasi yang memukau!

📑 Panduan Struktur Presentasi

Presentasi kelompok minimal memuat 8 komponen penting berikut:

  1. Masalah Nyata: Lokasi pos dan masalah kontekstual yang diamati.
  2. Data Lapangan: Besaran angka, harga, kapasitas, atau ukuran nyata.
  3. Definisi Variabel: Apa yang dimisalkan sebagai x dan y.
  4. Model SPtLDV: Sistem pertidaksamaan linear yang terbentuk.
  5. Garis Batas: Titik potong sumbu dan jenis garis (penuh/putus-putus).
  6. Daerah Penyelesaian: Hasil uji titik dan arsiran daerah solusi.
  7. Interpretasi Solusi: Apa arti daerah tersebut dalam konteks kehidupan sekolah.
  8. Kesimpulan: Rekomendasi keputusan optimal bagi warga sekolah.
💡 Format yang Didukung: File PPTX, PDF, atau kumpulan gambar presentasi (slide). File disimpan secara aman di browser kelompokmu.

🔥 Master Challenge — Evaluasi Akhir SPtLDV

Ujilah penguasaan komprehensifmu mulai dari konsep garis batas, titik uji, SPtLDV hingga interpretasi masalah nyata.

Soal Evaluasi Mandiri
Kerjakan dengan teliti. Jika ada kesalahan, kamu bisa mencoba lagi dengan petunjuk!
Nilai: - / 100

1. Garis Batas Penuh vs Putus-Putus

Sebuah pertidaksamaan memiliki bentuk 4x + 5y < 20. Pernyataan berikut yang benar mengenai grafik garis pembatasnya adalah:

Perhatikan tanda ketidaksamaan murni (< atau >). Apakah tanda itu memiliki garis bawah sama dengan?

2. Uji Titik Penyelidikan

Diberikan pertidaksamaan 3x - 2y ≥ 6. Apakah titik asal (0, 0) berada di dalam daerah penyelesaian?

Ganti nilai x dengan 0 dan y dengan 0. Apakah 0 lebih besar atau sama dengan 6?

3. Sistem Pertidaksamaan & Titik Irisan

Sistem pertidaksamaan: x + y ≤ 6, x + 2y ≤ 8, x ≥ 0, y ≥ 0. Berapakah koordinat titik potong antara garis x + y = 6 dan x + 2y = 8?

Kurangkan kedua persamaan: (x + 2y) - (x + y) = 8 - 6 → y = 2. Lalu cari nilai x.

4. Soal Kontekstual Parkir Sekolah (Input Jawaban)

Area parkir sekolah memiliki luas 120 m². Satu motor (x) membutuhkan 2 m² dan satu mobil guru (y) membutuhkan 10 m². Jika daya tampung maksimal kendaraan adalah 20 unit, dan jika sekolah memarkirkan 15 motor, berapa jumlah maksimal mobil yang masih bisa masuk? (Ketikkan angka bulatnya saja).

Cek dua batasan: Daya tampung: 15 + y ≤ 20 → y ≤ 5. Luas: 2(15) + 10y ≤ 120 → 30 + 10y ≤ 120 → 10y ≤ 90 → y ≤ 9. Ambil nilai yang memenuhi KEDUA batasan sekaligus!

5. Validasi Pernyataan Konseptual (Benar / Salah)

"Daerah Penyelesaian (DP) dari suatu sistem pertidaksamaan linear dua variabel selalu hanya berupa satu titik koordinat tunggal saja."
